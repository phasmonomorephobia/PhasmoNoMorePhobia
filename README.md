
# PhasmoNoMorePhobia

An open-source Phasmophobia companion application
built with Python and PySide6.

## Features

- Customizable information overlay
- Simple and Advanced view modes
- Application settings
- Customizable keybinds
- Streamer Mode
- Player statistics
- Ghost statistics
- Customizable overlay layouts

## Technologies

- Python
- PySide6
- Qt Widgets

## Installation

1. Clone the repository.
2. Create a Python virtual environment.
3. Install requirements.
4. Run the application.

```bash
python -m venv .venv
pip install -r requirements.txt
python src/main.py
```
